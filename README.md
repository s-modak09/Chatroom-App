## About

Chatroom App is a real-time group messaging application for Android.

Users can create an account, sign in, join available chat rooms, and communicate with other members in the same room.

The application is built using modern Android development technologies and follows the MVVM architecture with a Repository layer. Firebase is used for authentication and cloud-based communication, while Room Database is used for local data persistence.

The project demonstrates practical experience with Android application architecture, real-time communication, local database management, authentication, and modern UI development.

- User registration
- User login
- Firebase Authentication
- Chat room management
- Join available chat rooms
- Group conversations
- Real-time messaging

- Local data persistence using Room Database
- MVVM architecture
- Repository pattern
- ViewModel-based state management
- Kotlin Coroutines
- LiveData
